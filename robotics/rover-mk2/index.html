Autonomous Rover Mk II

📅 15 Nov 2025 ⏱️ 4 Min Read ⚙️ Hardware

This project involved integrating an RPLIDAR sensor into a custom-built rover chassis for real-time obstacle avoidance and mapping. The goal was to create a robust, self-navigating platform capable of traversing uneven terrain.

System Architecture

The navigation stack is written in Python, operating on ROS2 for seamless node communication. By offloading the heavy kinematic calculations to a dedicated coprocessor, the main Raspberry Pi 4 is freed up to handle the high-frequency LIDAR point clouds.

Sensory Input

  • RPLIDAR A1 (360° scanning)
  • MPU6050 6-DOF IMU
  • Ultrasonic fallback sensors

Drive System

  • 4x 12V High-Torque DC Motors
  • L298N Dual Motor Controllers
  • 10,000mAh LiPo Battery pack
