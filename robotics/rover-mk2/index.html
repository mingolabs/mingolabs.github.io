Autonomous Rover Mk II

Date: 15 Nov 2025

This project involved integrating an RPLIDAR sensor into a custom-built rover chassis for real-time obstacle avoidance and mapping.

Hardware Utilised

  • Raspberry Pi 4
  • RPLIDAR A1
  • L298N Motor Controllers

The Code

The navigation stack is written in Python, operating on ROS2 for seamless node communication.
